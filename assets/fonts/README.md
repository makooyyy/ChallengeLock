# Шрифты

Самостоятельно размещённые переменные шрифты из Google Fonts. Подмножества: `latin` и `cyrillic`, формат woff2.

| Семейство | Файлы | Авторы | Лицензия |
| --- | --- | --- | --- |
| Manrope | `manrope-latin.woff2`, `manrope-cyrillic.woff2` | The Manrope Project Authors | SIL OFL 1.1 |
| Oswald | `oswald-latin.woff2`, `oswald-cyrillic.woff2` | The Oswald Project Authors | SIL OFL 1.1 |
| JetBrains Mono | `jetbrains-mono-latin.woff2`, `jetbrains-mono-cyrillic.woff2` | The JetBrains Mono Project Authors | SIL OFL 1.1 |

Полный текст лицензии — в `OFL.txt`. При обновлении шрифтов возьмите variable-подмножества с Google Fonts, сохраните имена файлов и обновите `@font-face` в `css/app.css`.
